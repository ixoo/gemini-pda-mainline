The remote program checks the exact kernel and proc identity, then copies the
observer immediately. Optional USB and battery reporting occurs only after two
copies exist. Unlike the parent collector, absent USB status cannot suppress
the decision-bearing observer evidence. A second copy two seconds later must
be byte-identical for every terminal latch state.

Semantic validation
-------------------
- ABI-v2 state, count, overflow and transaction metadata are parsed exactly;
- count is bounded by 256 and retained sequence must be exact contiguous
  append order starting at one;
- wait-up, started, down-transaction and overflow state metadata are checked;
- frozen-complete requires distinct nonzero up/down transactions, CPU8 only,
  no overflow, contiguous transactions and the exact accepted timestamp-order
  up/down lifecycle and owner-record templates;
- lifecycle returns, DA9214 page restoration, SPM validity, secure stability,
  immediate clock evidence, mutation readback, raw/mapped PSCI identity and
  buck transitions reuse the source-pinned parent runtime analyzer; and
- every other state is preserved as incomplete or terminal failure evidence.
