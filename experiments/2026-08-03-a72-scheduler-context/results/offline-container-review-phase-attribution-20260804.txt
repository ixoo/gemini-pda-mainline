Corrected validation gates
--------------------------

The first validator hardening at repository commit `a86a7cc` replaced
substring-only provenance checks with unique exact key/value parsing, pinned
both sidecars and the complete manifest, rejected contradictory provenance,
and added candidate-root and link-count checks. Review then found that its
offline scan covered only the immediate assembler parent rather than the full
dynamically imported chain. No unconditional PASS was recorded from that
intermediate validator. Commit `396017d` pins and scans all 11 assemblers plus
the wrapper and source builders; both independent roots pass that final
validator and all six negative mutations.

Acceptance boundary
-------------------

This review fixes the exact phase-attribution artifact identity. It does not
authorize a device write by itself and does not establish a runtime result.
The current installed boot2 predecessor remains the rejected start-gate image
until a separately reviewed guarded installer proves otherwise. Device access,
partition write, boot selection, and runtime result were all absent here.
