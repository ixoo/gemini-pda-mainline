Inference and boundary
----------------------

The physical selection report, changed boot ID, watchdog-class recovery, and
unchanged boot2 establish a real candidate/recovery cycle. They do not
establish whether pair-v6 ran, whether pair-v7 reached either task, or whether
the blocked start gate passed. The retained pstore record belongs to the
recovery boot and cannot distinguish a terminal that was never reached from a
candidate terminal overwritten before collection.

This matches the fixed `AUTOMATIC RESTART WITH NO PAIR-V7` branch. Repeating the
same image is justified only because just-in-time USB/netcat plus changed-cycle
pstore provide a new independent observation path; it is not a repeatability
test and it does not weaken any pass field. Arm both observers immediately
before shutdown/physical selection, then classify only their attributable
changed-cycle evidence.
