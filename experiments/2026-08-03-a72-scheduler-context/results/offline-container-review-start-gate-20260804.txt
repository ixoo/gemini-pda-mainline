Acceptance boundary
-------------------

This fixes the exact start-gate artifact identity but does not bypass the
standing live-GPT-resolved inactive boot2 policy. Before deployment, the
installer must pin the current rejected rendezvous predecessor, validate exact
target identity, inactivity, size and power, verify full write/readback, remove
temporary state, and shut down cleanly. The runtime map must add all four new
ready/start fields and retain every complete pair-v6, recovery, and
serviceability requirement.
