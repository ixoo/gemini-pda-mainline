Deployment safety review
------------------------

The derived installer pins all four identities above and retains the reviewed
base installer's fail-closed gates:

- resolve exactly one boot2 from the live GPT;
- require boot2 to be inactive, unmounted, writable, exact-sized, and on
  stable power;
- require the exact predecessor or skip an already matching successor;
- record the predecessor checksum without creating a fresh partition backup;
- pad and write only the exact successor, then sync and flush;
- require an independent matching full-partition readback;
- remove temporary readback state; and
- shut down cleanly after success without requesting reboot.

The USB/netcat helper remains read-only on the device. Its remote program reads
only dmesg, kernel identity, and CPU online/present state. Static forbidden-
operation checks reject block-device paths, CPU-online writes, storage tools,
mounting, reboot, poweroff, shutdown, and kexec.

Capture and classifier review
-----------------------------

The collector emits complete numbered snapshots once per second and places a
leading newline before snapshot 1 so the inherited interactive USB-shell
prompt cannot prefix its control record. The host parser requires:

- contiguous, closed snapshot envelopes and exact payload counts;
- exactly one syntactically complete marker or pair terminal per payload line;
- one of the reachable parent control-flow prefixes and an exact per-CPU task
  prefix from a continuous create8-before history;
- monotonic full event history across cumulative snapshots;
- exact source-pinned pair-v6 and pair-v7 field schemas;
- the established exact pair-v6 and pair-v7 PASS vectors, including hashes,
  with fault fields that report successful waits activating their causal edges;
- adjacent final pair-v6/pair-v7 records immediately after run-exit whenever
  scheduler markers exist;
- exact equality between snapshot terminals and terminal metadata;
- all 39 phase records and PASS-only causal edges for pair-v7 pass; and
- a distinct transport-truncated class for an unclosed final envelope.

Marker-free inherited-parent faults, create-failure cleanup, timeout ordering,
and a normally entered path whose task never dispatches before kthread_stop
remain valid fault structures. They are not promoted to PASS. Pstore remains
the primary changed-cycle evidence; USB is secondary corroboration.
