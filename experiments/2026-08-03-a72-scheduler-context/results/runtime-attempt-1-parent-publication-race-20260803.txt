Observation versus inference
----------------------------

Observed: multiline and parallel completion proves the coherency work function
advanced through both later child phases. Nevertheless, `coh_reported` remained
the reset value `-1` at the terminal snapshot, and the scheduler snapshot still
contained only reset values.

Source-established cause: pair-v7 calls the bounded scheduler runner inside the
coherency work function before its inherited `publish` label sets
`coh_reported=1`. The independent terminal work can therefore snapshot all
completed multiline/parallel results while the inherited coherency publication
is still withheld by the new child phase. This violates the intended rule that
the child must not delay or redefine the complete parent predicate. The exact
instruction at which the two work items interleaved is not observable.

Next action
-----------

Change the source ordering rather than repeat the image. The inherited worker
must publish all parent results without waiting for scheduler execution. The
terminal path must snapshot and decide the complete parent predicate first,
run the scheduler child only after that predicate passes, then emit adjacent
pair-v6 and pair-v7 terminals. Preserve all existing power, HPS, CPU_OFF,
watchdog, workload, and recovery boundaries.
