Experiment: 2026-07-25-emmc-development
Candidate: AW (PMIC-wrapper-enabled eMMC development candidate)
Date: 2026-07-26
Device: named Gemini PDA under test
Test type: read-only runtime boot validation over direct USB Ethernet

Hypothesis
==========
Enabling CONFIG_MTK_PMIC_WRAP together with the already enabled MT6351 MFD,
regulator, and MediaTek MMC host symbols will allow the DT's VEMC and VIO18
supplies to resolve and the eMMC host to enumerate.

Observed
========
- Kernel: Linux 7.1.3-gemini-observability-L, aarch64, SMP.
- Runtime configuration reported:
  CONFIG_MTK_PMIC_WRAP=y
  CONFIG_MFD_MT6397=y
  CONFIG_REGULATOR_MT6351=y
  CONFIG_MMC_BLOCK=y
  CONFIG_MMC_MTK=y
- PMIC-wrapper probe: `1000d000.pwrap returned 0`.
- MT6351 child probe: `1000d000.pwrap:pmic returned 0`.
- MT6351 regulator probe returned 0.
- Named rails registered:
  `regulator.18` = `vemc_3v3`
  `regulator.24` = `vio18`
- MMC host probe: `11230000.mmc returned 0`.
- Card: `mmc0:0001 DF4064 58.2 GiB`.
- Block node: `/dev/mmcblk0` with partitions `p1` through `p33`, plus
  `/dev/mmcblk0boot0`, `/dev/mmcblk0boot1`, and `/dev/mmcblk0rpmb`.
- Eight CPUs remained available (`grep -c ^processor /proc/cpuinfo` = 8).
- USB shell remained reachable on the direct development link.

Post-boot boot2 readback
========================
The live GPT was inspected read-only. The `boot2` partition resolved to
`/dev/mmcblk0p30`; its sysfs size was 32768 sectors (16 MiB) and it was not
mounted. Reading exactly 16 MiB from that node produced:

`216daa467231d7a191b918584fa12fed6904429a020c1a2283fbf7ed82f74a0f`

This matches both the locally retained padded candidate and the post-install
full-partition capture byte-for-byte by checksum.

Safety
======
No partition was mounted or written. The probe used only `/proc`, `/sys`,
`dmesg`, and device-node listing. The initramfs still reports its inherited
AC shell identity; kernel configuration and hardware probe results are the
attributable AW evidence for this test.

Decision
========
PASS. The PMIC-wrapper dependency was the missing runtime piece. AW provides
working read-only eMMC access and supports the next step: an explicit helper
`--dry-run` GPT/boot2 audit before any development write.
