# Cassini result records

This directory is reserved for sanitized, exact-revision Cassini evidence.

Record build reproduction and mutation results before any installation. A
hardware record must include the installed raw and padded SHA-256 values,
predecessor and full readback identity, boot IDs, complete six-transaction
marker sequence, CPU mask, console/keyboard/USB result, native-reboot result,
and post-return pstore/readback evidence.

Do not store private keys, device dumps, serial numbers, MAC addresses beyond
the project-fixed diagnostic addresses, or proprietary datasheet content here.
