Compiled-order proof
--------------------
The compiler inlined the rollback orchestrator into cpu_psci_cpu_boot. The
actual arm64 image contains this order:

  ffffffc00008c7c4  call mt6797_a72_obs_accepts_sampling
  ffffffc00008c7cc  branch to the -EAGAIN exit when false
  ffffffc00008c7d8  first atomic one-shot load-exclusive
  ffffffc00008c7dc  atomic store-exclusive
  ffffffc00008c824  first owner call, clock capture

Thus the observer latch dominates both the compiled atomic mutation and every
hardware-owner call. The false branch reaches the common return with -EAGAIN;
it cannot consume the one-shot. The added check does not increase the previous
rollback candidate's 128-byte cpu_psci_cpu_boot stack frame.
