Publication/order review
------------------------

Every matching HPS CPU8/CPU9 `-EPERM` increments one atomic count. Exactly one
caller claims state `0 -> -1`, writes the first CPU and actual error, executes
`smp_wmb()`, then publishes state `1`. The read-only snapshot reads publication
state, executes `smp_rmb()`, and then reads first CPU/error/count. A snapshot of
`-1` is explicitly non-pass rather than being silently promoted.

The snapshot performs only atomic reads and one read barrier. The existing
sample-3 site is the only caller. Earlier pair samples/faults and all delays are
unchanged; the old sample-3 text alone becomes the unique self-contained
`pair-v3` terminal.
