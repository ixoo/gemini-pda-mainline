A72 same-version pmsg witness compile-lane validation
====================================================

Scope
-----

Local validation of the Buildbox-only exact-parent compile lane. No kernel
compile, boot image, candidate, device access, retained-RAM write, or hardware
action occurred.

Compile decision gates
----------------------

- Deterministic exact-parent/child source validation must pass before compile.
- Parent and child resolved configurations and extracted diagnostics must be
  identical; both must retain PSTORE, PMSG, RAM, and console pstore options.
- `pstore_write_pmsg_kernel` must be a linked child-only symbol.
- Compiled observer-entry and pre-scheduler sites must each add one writer
  call. The single source-level PASS/FAULT terminal operation compiles to two
  mutually exclusive static callsites; no other direct-call delta is allowed.
- The helper must contain exactly mutex lock, strcmp, and mutex unlock direct
  calls plus one indirect backend call, with the forbidden CPU, PSCI, MMIO,
  regulator, clock, delay, reset, and reboot call inventory absent.
- All four fixed pmsg records must be linked only in the child. The inherited
  console-marker inventory and both 26-MRS register-capture task inventories
  must remain identical.
- Focused stack reports must cover the writer, observer init, scheduler task,
  terminal, and parent worker within their fixed bounds.
- The package remains `boot_candidate=false` and compile-review-only.

Local validation
----------------

- `bash -n` passed for the shared compile script, pmsg wrapper, and Buildbox
  dispatcher.
- ShellCheck passed for the same three shell paths.
- The existing pmsg source self-test passed all eight negative mutations.
- `git diff --check` passed.
- The Buildbox help/dispatch surface exposes only the named pmsg build and fetch
  commands.

Decision
--------

Attempt 1 at project commit `bb3bc9c1627c31e56cdef3791bb1906ce1434130`
compiled both exact trees, then stopped before packaging because the gate
expected one terminal call instruction while GCC emitted two mutually
exclusive PASS/FAULT callsites. The corrected lane preserves the three exact
source operations and pins their four-callsite compiled topology. It is
accepted for one retry from a new clean pushed commit. Candidate construction
and all device action remain blocked until the fetched compile package
independently passes its checksum and provenance review.
